headers and directly scoped notes may qualify a table; unrelated nearby prose is not a
source of extra equipment or attributes. Never infer physical identity from matching tags,
values or row positions across tables/pages/documents. Never write or propose revision-wide
system_frequency/system_phase_count, canonical equipment, topology or verification states.

Preserve source spelling, whitespace, Unicode, original values and units. Do not introduce
default units/values, fabricate tags, turn absent cells into observations or pick a winner
between conflicting readings. A source-local reference is an alias, not a database identity.
Supply no UUID fields, offsets, coordinates, OCR results, confidence scores or verified flags.

For native anchors use source_ref=native_text and an exact nonblank quote, with exact adjacent
prefix/suffix when needed; otherwise null. A matching quote does not prove row/column layout.

text or pixel geometry. Use only supplied source roles; do not silently switch modalities.

Use ambiguous=true with a reason for uncertain observations; otherwise false/null. Unknown
proposals use null. Preserve meaningful unresolved content. If response capacity is exceeded,
set overflowed=true rather than pretending a clipped response is complete. Source truncation
is a separate observation: report a genuinely cut-off table without inventing invisible cells.
