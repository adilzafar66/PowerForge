# F1-A2 deterministic table reconstruction ablation

## Scope and method

The benchmark uses all seven approved engineering pages and the same source, fixture and renderer identities as F1-A2. The synthetic positioned schedule is a separate positive control, with a verified 2×2 table and two header links in the existing spatial layout regression. It stays out of the engineering coverage denominator. [F1-A2 scoring and baseline](F1_A2_REPORT.md)

The three arms use the existing preparation, layout admission and replay, and Stage 2 request assembly, with overrides scoped to the offline process:

- **Existing tables** runs native primitive extraction, ruled and borderless table inference, and normal reading construction.
- **Positioned only** skips native drawing enumeration and both table inference paths. It retains original PDF and image bindings, native and OCR text, positioned reading IDs, witness groups, conflict flags, and the existing engine-local ordering rules.
- **Simple lines** applies the same bypass. It adds short, same-baseline adjacency links between nearby readings from the same source representation. The rules respect existing predecessor and successor edges and known reading issues. The links do not assert a schedule row, column, header, or equipment relationship.

Each arm ran under default OCR eligibility and forced full-page hybrid, twice per page, with arm order rotated on the second attempt. The positive control used default OCR eligibility. Source preparation and layout overrides have distinct evaluation-only identities, and the normal layout admission code reproduces each arm's manifest from its exact sources under the corresponding identity. The original analysis image is identical across arms for a page. No provider transport is used.

Timed attempts include prepare, layout, pin and replay, and request packing. The shared analysis render and descriptive scoring are separate. A separate instrumented baseline pass times native drawing enumeration and primitive conversion, native segment projection, grid connectivity, the inclusive ruled partition and assignment routine, the inclusive borderless routine, and independent reading alignment. Boundary coverage and cell containment timings are nested within ruled-grid work. Cell containment describes the containment predicate only. It omits candidate enumeration, ambiguity checks, creating cells, and header processing. Header timing includes calls from either structural path. The profiler sees layout derivation and the replay the offline loader performs. It does not include all the database, storage, queue and worker publication costs in a production enrichment job.

Coverage uses the corrected preferred, available and unambiguous scoring. Exact reading fingerprints check text, positions and IDs, and a separate witness fingerprint checks source representation, alternate text and uncertainty. A bounded probe replays up to 128 preferred reading IDs with literal quotes and a separate bounded set of page-local quote citations. It compares exact evidence outcomes and value-text eligibility, with random artifact IDs removed from the fingerprint. The Stage 2 body uses the fixed synthetic BUS prerequisite and the current compact-page-v1 serializer, with the same image and prompt across arms. The source JSON and full body byte counts use this one fixed workload. Stage 1 serialized size and model behavior remain open.

```sh
.venv/bin/python evals/phase6r/f1a/evaluate_table_ablation.py \
  /Users/adilzafar/Downloads/equipment-drawings \
  /tmp/table-ablation-results.json --repeats 2
```

Run with a local Tesseract 5 engine and English language data. The recorded run used the existing source-worker runtime in a network-disabled container with read-only inputs. The report stores timing and scoring results without retaining original PDFs or raw transcripts. [Machine-readable results](table-ablation-results.json)

## Measured results

All 90 scored attempts completed. Repeats matched on reading, witness, layout-summary and evidence fingerprints, and on request sizes. Below, times sum the mean of two attempts for each of seven pages. Packed source size excludes the image and the rest of the request envelope.

- **Default OCR eligibility** · Existing tables took **11.62 s** and packed **236.4 KiB** of source JSON. Positioned only took **5.89 s** and **222.3 KiB**. Simple lines took **5.89 s** and **224.0 KiB**. Positioned only reduced local time by **49%**, source JSON by **6%**, and the complete image-bearing provider body by **0.44%**.
- **Forced full-page hybrid** · Existing tables took **25.91 s** and **862.0 KiB**. Positioned only took **19.67 s** and **855.5 KiB**. Simple lines took **19.89 s** and **856.4 KiB**. Positioned only reduced local time by **24%**, source JSON by **0.75%**, and the complete provider body by **0.17%**.
- **Reading and grounding retention** · All arms preserved the exact reading IDs, text, alternate witnesses, overlap issues and coordinates. All kept **1,758 positioned readings** with default eligibility and **2,720** with forced hybrid. The respective preferred, available and unambiguous coverage counts were **371 / 371 / 371** and **401 / 407 / 333** out of 490. Geometric association scores were identical within each OCR mode. All sampled reading and quote outcomes also matched across arms. Default eligibility resolved 891 sampled reading citations and 426/693 quote citations. Forced hybrid resolved 896 reading citations and 123/698 quote citations, with 795 reading fragments and 99 quote fragments eligible as reliable value text.
- **Ordering retention** · Under default eligibility the existing path emitted 1,018 same-baseline, 2 table-row and 8 table-column links. Positioned only retained 1,011 same-baseline links. Simple lines emitted 1,068 same-baseline links, adding 57 over positioned only. Under forced hybrid the three arms emitted 1,089, 1,089 and 1,118 respectively. Those added links are proximity hints. They received no verified table credit or demonstrated AI accuracy gains.
- **Verified structure** · Existing default eligibility emitted one Eaton table that matched none of the approved scored cells. Existing forced hybrid emitted none. All three arms retained the F1-A2 result of zero verified structural pairs in the engineering fixture set. The synthetic positive control was different. The existing path retained four cells, two header links and one caption, while the two table-free arms retained the eight positioned readings and their citation behavior. Stage 2 source JSON dropped from 5.37 to 2.85 KiB on that control because it no longer conveyed the real structure.

The ablation skipped table attempts and their limitations by design. On the engineering pages it bypassed two native drawing primitive limits, one grid-component limit and two partition limits in each OCR mode. It also bypassed the irregular-grid and ambiguous-assignment diagnostics. These limitations were avoided by omitting the capability. The experiment did not resolve the previously uncertain relationships or change reading, OCR, raster or request limits.

### Where the local cost came from

The independent profiling pass used one attempt per page and OCR mode. Stage totals below come from the main two-repeat run. Profile categories overlap where marked.

- **Preparation and replay** · With default eligibility, disabling tables reduced preparation from 2.60 to 1.23 s, layout from 2.22 to 1.04 s, and pin-and-project from 6.61 to 3.39 s across the corpus. With forced hybrid the same stages went from 11.68 to 10.13 s, 3.40 to 2.22 s, and 10.48 to 6.95 s. Prepared geometry bytes fell from **1,318,290 to 580,283** with default eligibility and **1,929,458 to 1,191,451** with hybrid. These stage deltas include building, hashing, decoding and revalidating native geometry alongside the rest of the pinned source. They cannot be attributed to cell assignment alone.
- **Native primitive extraction** · Enumerating and converting drawing items took 278 ms across the default-eligibility profiling pass and 351 ms under hybrid. Delta alone took 211 ms and 235 ms before reporting its native primitive limit. PyMuPDF enumerates drawing items before PowerForge can apply its output cap.
- **Segment projection and grid detection** · Native segment projection took 664 ms under default eligibility and 628 ms under hybrid, including the loader replay. Grid connectivity took a further 272 and 276 ms. REX accounted for roughly 584 and 545 ms of segment projection, and 219 and 221 ms of connectivity. Its attempt hits the grid-component limit before the partition and cell assignment routines run.
- **Partitioning, assignment and headers** · Inclusive ruled partition and assignment took 15.50 ms under default eligibility and 2.80 ms under hybrid for the components that reached it. Borderless processing took 1.00 and 1.10 ms. Within ruled processing, boundary checks took 0.74 and 0.75 ms, and the cell containment predicate took 0.99 and 0.11 ms. Header assignment took 0.096 ms in the default-eligibility pass and did not run in the hybrid pass. These nested timings cannot be added to their parents. The synthetic control showed that a small clean grid can preserve real structure at low cost.

**REX drove most of the measured speedup.** It fell from **5.89 to 0.96 s** under default eligibility and **8.66 to 3.67 s** with hybrid. Its source request shrank by about 0.07 KiB because there was no reconstructed table to omit. Outside REX, positioned-only reduced the combined default-eligibility time by about 0.80 s and hybrid time by 1.26 s. This is primarily a local processing and artifact-size improvement on expensive geometry, with a much smaller effect on AI input bytes.

## Recommendation and controlled-evaluation gate

**Candidate for simplification** · Keep the pinned positioned layout as the required output. Separate primitive extraction and table reconstruction from that required path so a versioned positioned-only mode can skip both. Keep native and OCR text, reading IDs, conflicts, alternate witnesses, coordinates, the original image and source identity checks. Preserve layout admission and the audit trail. Distinguish table enrichment that was skipped from an attempted reconstruction that was unresolved.

**Retain as optional enrichment** · The ruled and borderless paths can add real structure on clean schedules. Keep that option available pending a representative benchmark that includes clean native tables and problematic engineering drawings. The experiment supports a route to avoid paying for costly geometry on difficult pages. It does not establish a reliable automatic selection rule.

**Simplified lines** · Keep the experimental proximity hints as a comparison arm. They added little wall time and a small amount of source JSON, with identical text and evidence coverage. They have not demonstrated a downstream benefit over the simpler positioned-only candidate.

**Requires separately authorized AI evaluation** · Run matched Stage 1 and Stage 2 on held-out drawings with native ruled, borderless and merged-header schedules, outlined engineering sheets, and OCR-heavy scans. Pin the image, readings, model, prompt, schemas, reasoning effort and budgets. To isolate Stage 2, first use equivalent pinned recognition content tied to each variant's page identity, then compare complete two-stage runs. Measure equipment recall and qualification, attribute accuracy, units and header interpretation, schedule row and equipment ownership errors, source-citation selection, repeated-value ambiguity and stage latency. Include the compact and readable profiles before changing their behavior. Use deliberately wrong, nearby values to score false associations. The result of that comparison determines whether positioned-only can become the default or table enrichment should remain enabled on particular workloads.
