# F1-A source coverage and preparation

The investigation used all seven pages of the six approved, SHA-256-pinned PDFs. The Schneider input is the replacement 800a MDB sheet. The earlier live investigation remains a separate benchmark. The gold contained 490 scorable text annotations when excluding one ambiguous annotation and diagram-only regions. The evaluation tests local source preparation and serialization, with zero paid provider calls and no production behavior changes.

## How the comparison was run

The existing arm ran the production eligibility, bounded preparation, layout, source-binding replay and Stage 2 request builder. The native-only control disallowed OCR. Full-page and regional OCR supplied OCR readings only, even when native text was available. Those two arms intentionally supplied no native table geometry. The forced hybrid retained both native and full-page OCR, using the production alignment rules. These comparisons distinguish text recovery from structural recovery. The regional experiment used at most six spatially fixed, ink-screened crops with a 2.5% overlapping halo. Each crop was OCR’d with the same single-threaded Tesseract configuration. The result was moved back into the page frame and each word was assigned to the crop core containing its center. Crops used no gold text or geometry.

Every page and mode completed two timed attempts with the mode order rotated. The renderer for the original analysis image ran once per page before the arms. Timed arms include preparation, layout, pin/replay verification and request assembly. Scoring ran afterwards. Timings measure a local Docker runtime with an in-memory store and serialize no remote work. Per-arm output records stage timings, text and coordinate fingerprints, OCR confidence, overlap diagnostics, table limitations and request sizes. [Machine-readable results](results.json)

Stage 2 used the real `compact-page-v1` serializer, `core-catalog-v1` prompt variant, `server-owned-assertions-v1` schema and medium reasoning configuration. A fixed synthetic recognition prerequisite containing one BUS observation kept catalog overhead comparable. This measures source bytes and exact encoded body size for that scenario. The UTF-8 bytes divided by four field is a coarse text-only token proxy. Actual provider token counts, costs, time to inference and equipment-specific catalog overhead remain unmeasured. All modes kept the matched analysis image in the hypothetical request.

### Scoring

- **Located coverage** requires a contiguous literal in readings whose centers fall inside the annotated region or cell. Exact comparison folds whitespace runs. A separately counted display-variant match tolerates the documented glyph class and inter-token whitespace. Case, digits and decimal spelling are preserved. Combined and per-engine spatial views are tried, so the presence of a competing transcript can still reduce usability even if the correct one counts toward coverage.
- **Numeric-literal coverage** matches the local multiset of digit sequences, including the exact decimal spelling. It includes numerical parts of ratings, identifiers and qualifiers. A numeric hit alone provides no claim about units, sign, context or ownership. **Transcription error** sums local character edit distances divided by the number of expected characters. For a miss, the scorer uses the nearest available local view. Missing text contributes a deletion for each expected character. Extra local text can contribute insertions.
- **Geometry** uses the matched readings’ envelope against the annotated region. The report gives both the fraction of the predicted envelope inside the annotation and intersection-over-union. The human boxes vary from cell-sized to paragraph-sized. Score these as region-level localization measures.
- **Schedule association** requires support in explicit predicted table cells. Adjacent annotated row and column pairs must align to the same predicted table in the correct order. Declared column headers require actual header links. Label/value pairs are evaluated on grids with a `label` column. Other authored diagram or markup relationships remain ground-truth review targets and carry no automated association credit.
- **Duplicates and uncertainty** are reported independently. Identical text at distinct locations remains distinct. Same-location identical pairs require at least 80% overlap of the smaller box. Cross-engine conflicts and ambiguous matches come from the production alignment diagnostics. OCR confidence below 50 is a descriptive count on Tesseract’s 0–100 scale. It has no role in acceptance or normalization.

## Measured results

All **70 page-arm attempts** reached request packing without a stage failure. The prepared, constructed and packed reading fingerprints repeated across the two runs for each page and arm. Every constructed reading’s text, alternate text, identity and coordinates survived the provider projection. Table payloads also matched their pinned layouts. No text loss was attributable to the tested packer. All bodies fit the 4 MiB transport ceiling. Body sizes ranged from 423 to 1,121 KiB. The largest combined representation contained 710 tokens before alignment, below the 4,096 layout-reading boundary.

Each entry below reports located annotations, located numeric literals, character error rate, median local time per page, and median packed source JSON size.

- **Existing preparation** · 371/490 (75.7%), 487/588, 18.25%, 1.00 s, 34.6 KiB.
- **Native text only** · 371/490 (75.7%), 487/588, 18.25%, 1.00 s, 34.6 KiB. Existing eligibility ran zero OCR calls on this corpus. On REX and Simson it requested explicit selection because of raster content.
- **Full-page OCR only** · 210/490 (42.9%), 370/588, 31.74%, 2.31 s, 40.6 KiB. This arm filled 33 baseline misses and lost 194 baseline matches.
- **Regional OCR only** · 256/490 (52.2%), 439/588, 27.56%, 2.82 s, 41.3 KiB. It filled 34 baseline misses and lost 149 baseline matches. Most of this improvement over full-page OCR came from the Simson tables, with the cost of six local engine invocations on these pages. The six-crop approach remains experimental.
- **Forced hybrid** · 401/490 (81.8%), 565/588, 6.95%, 3.34 s, 125.0 KiB. This arm added 30 located annotations and 78 numeric literals over the baseline. All 371 baseline matches still scored as located. OCR added 206 same-location identical reading pairs, 42 diagnosed cross-engine conflicts and 463 ambiguous overlap pairs. A recovered literal can coexist with conflicting or redundant readings.

Mean matched-box containment was 0.990–0.994 across the five arms. Mean overlap with the full gold region was 0.317–0.409. These are conditioned on located text matches and should be read alongside coverage. Full-page OCR reported 298 of 1,890 words below confidence 50, while regional OCR reported 205 of 1,869. Lower counts and smaller requests alone did not correspond to higher coverage.

The scorer recovered **0 of 221 row pairs, 0 of 270 column pairs, 0 of 152 header links and 0 of 69 label/value pairs** across the annotated structures in every arm. The single inferred baseline table on Eaton did not align any scored cell. Forced hybrid produced no tables, and the Eaton layout added an ambiguity diagnostic. OCR recovery cannot establish schedule ownership on these drawings. This result concerns the emitted deterministic structure, while a human or vision model can still use the page image.

## Findings by document

- **Delta** · **50 / 50 / 15 / 19 / 50** of 63. All 125 reviewed numeric literals were available with native text. The source retained 348 words despite exceeding the 5,096 native-primitive cap. The page has no embedded rasters and the drawing contains over 151,000 line items. Native tap-text locations survived, while the optional table structure was withheld. Forced OCR added no located match and produced 14 cross-engine conflicts. Time was 1.35 → 3.75 s. Packed source was 41.6 → 168.2 KiB.
- **Eaton** · **82 / 82 / 67 / 55 / 82** of 83. Native readings covered all 75 numeric literals, including the position numbers. The 62 native primitives still left three irregular-grid diagnostics. The ruled geometry did not prove the Branch Devices or Main Devices associations in the fixture. Hybrid added 15 conflicts and an ambiguous assignment, with no text gain. Time was 1.15 → 3.54 s. Packed source was 51.4 → 176.7 KiB.
- **REX** · **63 / 63 / 53 / 55 / 68** of 79. Native positioning retained 304 words and 4,629 primitives. The grid-component limit removed optional tables before publication. The PDF has 91 raster placements. Native coverage gaps include the bare front dimensions and some winding labels. Hybrid added five located matches and six numeric literals. At construction, the grouped insulation line lost its complete local transcript while all three numeric literals remained. The NEMA terminal note shifted from exact to display-variant. The packer retained the resulting readings in both cases. Time was 6.11 → 9.00 s. Packed source was 37.7 → 166.2 KiB.
- **Schneider 800a MDB** · **1 / 1 / 23 / 23 / 24** of 81. The plain native-text artifact contained 791 characters. Visual inspection and a PyMuPDF span check found no native text in the schedule or specification blocks. Thirty of 32 native spans were in the review stamp, and the exact located baseline match was the red electronic-trip note. The sheet has zero embedded rasters and over 20,000 drawn line items. The evidence is consistent with outlined engineering lettering. Removing native primitives at the cap explains the absent deterministic table geometry, while the missing technical text was already absent before preparation. OCR recovered the 800 A bus and system statements and the PS position labels. It found all six enclosure dimension numerals locally, but the complete dimension string still differed. The SCCR annotation failed the numeric and whole-transcript checks in every arm. Hybrid preserved the trip note and reached 72 of 86 local numeric literals. Time was 0.49 → 3.34 s. Packed source was 17.1 → 101.5 KiB.
- **Siemens** · **38 / 38 / 40 / 39 / 38** of 40. Native readings captured all 64 numeric literals, including branch ratings. The largely open format emitted no table relationships. Full-page OCR found two more text annotations than baseline. Their numeric literals remained. This makes reading construction a separate benchmark failure point even though all final packed readings were retained. Time was 0.87 → 2.80 s. Regional OCR recovered 53 more annotations than full-page OCR, particularly conventional rows under colored section bands. Native remained more complete, and hybrid only added one match per page. ## Adaptive preparation assessment

A fixed, gold-blind diagnostic divided the downsampled analysis image into 16 tiles. It selected forced hybrid when at least three tiles contained ink but no native reading center. On this corpus the rule selected REX, Schneider and Simson page 1. The replay would have reached **400/490 annotations**, compared with 401 for forcing hybrid on every page and 371 for existing preparation. Its estimated processing time was **18.76 s across seven pages**, plus 0.16 s to compute the signal. Always using hybrid took 26.37 s and existing preparation took 11.96 s, excluding the common analysis render. This is a counterfactual timing from measured arms. The experiment has no held-out test of the threshold, and a coarse ink tile cannot distinguish text from geometry.

**Recommendation.** Retain native text and the page image as the default. Evaluate a conservative page-level OCR suggestion on held-out documents, initially under the existing explicit enrichment choice. Schneider shows why a native character count and the presence of embedded rasters are insufficient signals. Simson and Eaton show why indiscriminate OCR is costly. Keep baseline text and layout available in any hybrid design, preserve engine disagreements for review, and expose source coverage and structure degradation separately. Keep the regional arm for investigation of dense table crops and layout-aware OCR. It cost more per page than full-page OCR, and selective hybrid recovered more of the reviewed text.

The following changes need architectural approval before production work:

- Automatic OCR invocation or new admission logic based on estimated coverage. Validate trigger precision, processing cost, immutable identities and user selection first.
- Publishing OCR crop results with crop-level input artifact hashes, bounded transforms, ownership and reproducibility. The experiment maps crop positions into an exact page raster and retains per-crop digests, without publishing those results.
- Region-local structural inference for outlined and dense tables, or independent eligibility for clean native and OCR-enhanced layout output. Require row, column, header and ownership acceptance cases. Preserve explicit ambiguity wherever the structure cannot be verified.

The corpus is small, selected for development and weighted by its reviewed annotations. These measurements establish neither general OCR accuracy nor provider extraction quality. The result supports advancing to review of the next F1 milestone with the current source-preparation defaults. F1-B, prompt changes and production source behavior are outside this investigation.

## Verification

- The ground-truth verifier checked all six source hashes and all seven page indices against the approved files.
- The Linux source-worker image `sha256:70dce6860df38c75a409abf325a600bb1ed8e774626752c8d198fbcc9c7df451` ran Tesseract 5.3.0 and PyMuPDF 1.28.2. The container used `--network none`, read-only source mounts and a temporary output mount.
- Host checks passed 37 F1-A, native and compact-context tests. A separate host run of the OCR and spatial suite found four failures because the host lacked the Linux Tesseract binary. The Linux rerun passed **52 tests**, including those four, with zero skips. The focused suites were `evals/phase6r/f1a`, `tests/test_enrichment_ocr.py`, `tests/test_spatial_evaluation.py`, `tests/test_enrichment_native.py`, and `tests/test_extraction_compact_context.py`.
- The pilot exposed two benchmark harness bugs, a strict registry enum constructor and an attempted v2 unpack of v1 input. The corrected harness verified an actual locally assembled Stage 2 request in the focused suite and in every official benchmark attempt.
